Descripción: Análisis de información de empleados y nómina para analizar los comportamientos y evidenciar un mejor análisis en temas de salario, compensación 
y demás normativas Colombianas de forma interactiva y precisa de la información. Ademas, La limpieza y transformación de los datos se realizaron utilizando Power Query, 
incluyendo el tratamiento de tipos de datos, períodos y valores inconsistentes.

Nota: Por tratarse de una prueba técnica realizada durante un proceso de selección, no se incluyen el archivo PBIX ni los datos originales.

Herramientas: Power BI, DAX, Power Query, Data Modeling y Excel.
